# KIR-33 Stage A 验收证据：报价与销售订单双向关联

- 日期：2026-08-11
- 分支：`feat/kir-33-stage-a`
- 基线：`origin/main` / `796256b`
- 范围：仅 Stage A；未进入 B、C、D，未发布生产。

## 交付结果

- 新增 `POST /api/document-sets/:id/sales-order`，内部用户无需客户确认即可从已关联客户的报价创建草稿销售订单。
- 转换同时要求 `document_sets:manage` 与 `orders:create`，并对报价 owner、客户 owner 和租户 RLS 取安全范围。
- 054 迁移在销售订单上保存来源报价 ID、报价号、源版本、完整内部快照和幂等键；同一报价数据库唯一。
- 同一报价的重复请求返回同一订单；不同请求键重试仍不重复建单；请求键跨报价复用返回冲突。
- 报价响应回链 `sales_order_id`；订单响应回链 `source_quote_id`、`source_quote_number`、`source_quote_version`。
- 来源内部快照保留产品 ID 与成本，但明确不进入订单 API、Web 或审计投影。
- Web 单证工作台新增内部幂等建单入口；订单列表和订单详情可回到指定来源报价。

## 数据与回滚

- 迁移：`db/migrations/054_kir_33_stage_a_quote_order_link.sql`。
- 054 仅扩展已有 `sales_orders`，沿用该表 RLS 和应用角色授权；来源报价使用 `(tenant_id, id)` 组合外键。
- `DOWN` 删除 054 索引、约束和五个来源字段，不修改已发布 053 文件。
- 回滚/前滚演练结果：054、053 依次回滚，再按 053、054 前滚；校验和一致。随后从 051 历史基线前滚至 054，自定义角色授权保持。

## 安全断言

- 其他租户 JWT 转换报价返回 404。
- 缺少 `orders:create`、即使持有 `document_sets:manage`，转换仍返回 403。
- 缺少客户时返回 `QUOTE_CUSTOMER_REQUIRED`，不生成订单。
- 订单响应和审计详情均不包含 `source_quote_snapshot`、`cost_unit_price` 或测试成本值。
- 数据库内部快照保留源版本 1 和成本；报价更新到版本 2 后，订单来源版本及快照仍为版本 1。
- 三次转换重试后数据库仍只有一张来源订单，转换审计也只有一条。
