# KirinDesk 操作手册（使用者版）

> 面向租户管理员 / 业务员的日常操作说明。本手册按系统真实页面与导航编写。
> 系统访问地址（上线后）：https://www.kirindesk.com

---

## 一、三种登录身份（重要）

KirinDesk 有两套完全隔离的登录入口，别搞混：

| 身份 | 登录地址 | 谁用 | 能做什么 |
|------|----------|------|----------|
| **租户用户**（你和你的业务员） | `https://www.kirindesk.com/login` | 公司内部员工 | 客户、订单、采购、提成等全部业务功能 |
| **平台管理员**（你，运营 SaaS 的身份） | `https://www.kirindesk.com/platform/login` | 你作为 KirinDesk 运营方 | 开通/管理租户、支持访问授权 |

**登录需要三样东西**（租户用户）：
1. **租户标识（slug）** — 你公司在系统里的唯一代号
2. **邮箱** — 你的登录账号
3. **密码**

> 你本次部署设定：邮箱 `service@kirindesk.com`，密码 `Aa@123456`，租户标识在开通租户时确定。

## 二、第一次进系统：从零到能下单

登录后顶部有一排导航菜单。建议按下面顺序把基础数据建起来：

### 1. 设置（`设置`菜单）
先去「设置」确认公司信息、默认币种等基础配置。

### 2. 建角色和用户（`角色` → `用户`）
- **角色**：定义谁能看什么、能改什么（比如"业务员"只能管自己的客户，"经理"能看全部）。系统用 RBAC 权限控制，先建好角色再建人。
- **用户**：把你的业务员一个个加进来，分配角色。每个用户用自己的邮箱登录。

### 3. 建客户和供应商（`客户` / `供应商`）
- **客户**：你的海外买家。点「客户」→「新建」，填公司名、联系人、联系方式等。
- **供应商**：你的上游工厂/采购来源。操作同上。
- 两个列表都支持 搜索 / 筛选 / 编辑 / 软删除（删除可恢复，不是真删）。

### 4. 录订单（`销售订单` / `采购订单`）
- **销售订单**：卖给客户的单。新建时选客户、填订单号、金额、明细行等。
- **采购订单**：向供应商下的单。新建时从下拉选供应商。
- 订单号同一租户内不能重复（重复会报错）。

### 5. 文件（`文件`菜单）
上传合同、PI、装箱单等附件。单文件上限 25MB，下载用一次性短期签名链接（安全，链接用过即失效）。

## 三、进阶业务功能

### 提成（`提成`菜单）
完整的提成管理子系统：
- **提成汇总**：总览
- **提成订单**：按订单算提成
- **提成方案表**：定义提成规则（比例、阶梯等），可新建多套
- **提成结算**：按周期结算，可查结算明细
- **提成发放**：结算后的实际发放记录

### 报表（`报表`菜单）
业务数据的汇总报表。

### AI 功能
- **OCR**：上传单据图片自动识别文字（如发票、PI）
- **AI 补全**：辅助填写/补全内容

### 审计（`审计`菜单）
所有敏感操作（登录、改权限、改数据、上传下载、导出等）都有不可篡改的审计日志，带哈希链防伪。出问题可追溯。

### 支持访问（`支持访问`菜单）
当你需要 KirinDesk 官方帮你排查问题时，在这里授权——必须你主动授权、限定范围和时限，官方才能临时访问你的数据，全程留痕。默认官方碰不到你的业务数据。

---

## 四、订阅与账单（你作为付费客户）

- **套餐（`套餐`菜单）**：查看当前订阅计划、配额用量（如客户数、订单数上限）。
- **账单（`账单`菜单）**：查看发票列表、支付状态，点「支付」完成缴费。
- **通知（`通知`菜单）**：配置系统邮件通知（发到你设置的邮箱）。

---

## 五、平台管理员功能（你运营 SaaS 时用）

从 `https://www.kirindesk.com/platform/login` 单独登录后：

- **租户管理**：开通新租户（新客户公司）、查看/管理已有租户。这是你给新客户开账号的地方。
- **支持授权**：管理你对各租户的支持访问申请。

> 平台管理员和租户用户是两套独立 token，登录平台控制台不会影响你的租户登录，反之亦然。

## 六、典型日常流程示例

**业务员接到一个新客户的订单：**
1. 「客户」→ 新建客户（如果是新客户）
2. 「销售订单」→ 新建 → 选该客户 → 填订单号、金额、明细
3. 需要采购 → 「采购订单」→ 新建 → 选供应商
4. 上传合同/PI 到「文件」
5. 订单完成后，提成在「提成」里按方案自动/手动结算

**月底对账：**
1. 「报表」看业务汇总
2. 「提成」→ 结算 → 发放
3. 「账单」缴当月 SaaS 订阅费

## 七、常见问题

- **登录提示租户标识错误**：确认 slug 拼写，区分大小写。
- **看不到某个菜单/页面提示无权限**：你的角色没有该权限，找管理员在「角色」里加。
- **删错了数据**：多数是软删除，能恢复，联系管理员或在列表里找已删除项。
- **网址变成一长串 `xn--` 乱码**：说明网址里混进了中文标点或空格，正确地址永远是干净的 `https://www.kirindesk.com`。
