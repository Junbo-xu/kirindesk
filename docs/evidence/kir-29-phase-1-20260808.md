## 安全断言

- 跨租户使用其他租户 JWT 读取单证 ID 返回 404。
- 无成本权限但有单证读取权限的用户响应中不存在成本价、成本合计或内部合计。
- `products:view/manage=own|assigned` 的列表、详情和更新均按 owner 收紧；正反路径均有集成测试。
- `document_sets:view=all` 与 `document_financials:view=assigned` 按每个单证 owner 取交集：自己的成本可见，其他 owner 的成本去敏。
- 产品与单证审计 before/after 使用最小投影；有 `audit_logs:view`、无目标财务 scope 的用户读取详情也得不到成本、内部费用或毛利。
- 单证图片引用执行 `files:view` scope，PDF 资产解析执行 `files:view`/`files:download` 交集；同租户其他用户文件在创建和遗留导出两条路径均被拒绝。
- 普通装箱逐明细生成箱行；合并装箱按箱号聚合明细并精确汇总重量/体积，PL 渲染两种模式的输出行为不同。
- PDF 渲染测试替身收到的对象只有公开投影，不存在内部成本字段。
- 原始追踪令牌不落库；数据库值等于原始令牌的 SHA-256，且不等于原始令牌。
- 匿名令牌解析函数固定 `search_path`、撤销数据库 `PUBLIC` 执行权，并在解析层排除已作废链接。
- 更新草稿到 v2 后，v1 链接仍返回 v1 售价与快照。
- 打开、下载、确认各形成独立事件；作废后匿名读取返回统一 404。
- 重复确认返回首次确认时间且不重复写入确认事件。
- 锁定后 API 更新返回 409，数据库触发器同时阻止绕过服务修改。
